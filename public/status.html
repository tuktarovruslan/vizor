Как подключить проект

Vizor ищет в корне warehouse папки с файлом vizor.json и опрашивает описанные там сервисы. Новый проект появится на странице без перезапуска. Те же манифесты использует node dev.mjs для запуска сервисов. Расположение плиток запоминается в браузере.

{
  "name": "my-project",
  "services": [
    { "id": "api", "type": "backend", "stack": "Node", "dir": "api",
      "command": "npm run dev", "url": "http://localhost:3100", "health": "/health" }
  ],
  "links": [
    { "from": "web", "to": "api", "label": "/api proxy", "via": "/api/health" }
  ]
}
